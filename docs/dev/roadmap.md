# План разработки

Реализованы [обмен между APP](../app-exchange.md), [постоянный сервис с вебхуком](../webhook.md), [делегирование файлов](../delegated-files.md), [членство и пермиты](../permissions.md), [почтовое восстановление](../passkeys.md) и [реестр раннеров](runners/registry.md).

Следующий этап — раннер Codex и веб-чат. Критерии приёмки — одноразовое поручение возвращает результат по схеме, постоянная сессия сохраняет историю после переподключения.

Перед подключением MCP к раннеру Codex нужно определить, от чьего имени выполняется запрос, какие права получает сервер и как отзывается доступ. Проверка должна охватывать и серверы из пользовательской конфигурации Codex.
