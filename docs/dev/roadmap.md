# План разработки

Реализованы [обмен между APP](../app-exchange.md), [постоянный сервис с вебхуком](../webhook.md), [делегирование файлов](../delegated-files.md), [членство и пермиты](../permissions.md), [почтовое восстановление](../passkeys.md) и [реестр раннеров](runners/registry.md).

Следующий этап — [профили раннеров](runners/profiles.md), раннер Codex и веб-чат. Критерии приёмки — USER или агент настраивает подключение профиля, исполнитель запускается в пределах его `scope`, одноразовое поручение возвращает результат по схеме, постоянная сессия сохраняет историю после переподключения.

Для внешнего [раннера Codex](runners/codex.md) согласованы отдельная установка CLI и [политика MCP](runners/mcp.md). При интеграции предстоит проверить весь путь от реальных пермитов контроллера до запуска и отзыва доступа у исполнителя, а также восстановление после сбоя раннера.
