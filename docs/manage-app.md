# Управление APP

Войдите в панель как администратор и нажмите имя APP в списке нод. Карточка показывает статус, последнюю проблему, число занятых слотов и количество ожидающих вызовов. **Обновить состояние** запрашивает свежие значения и сохраняет введённый в редактор текст.

**Остановить** закрывает приём вызовов. Вызовы из очереди сразу получают ошибку. Активный процесс получает SIGINT и может успеть отправить ответ. Через десять секунд раннер посылает ещё работающему процессу SIGKILL. Статус `stopping` означает, что завершение ещё ожидается. После остановки нажмите **Запустить**, чтобы APP снова принимала вызовы. Процесс запускается при первом назначении.

Чтобы изменить команду, аргументы или контракт, отредактируйте **Источник манифеста JSON** и нажмите **Сохранить манифест**. Встроенный манифест задаётся объектом `{"manifest":{…}}`, файловый — объектом `{"file":"/абсолютный/путь","override":{…}}`. Ошибка проверки оставляет прежний источник. Постоянный процесс сохраняет текущие настройки и контракт до выхода. **Перезапустить** позволяет применить изменения с сохранением очереди. У одноразовых процессов новый контракт действует сразу, старые исполнители заканчивают принятую работу. [Файловые манифесты и webhook](webhook.md)

Эти операции доступны через `call` при наличии пермита на соответствующий метод.

| Метод | Параметры `data` | Результат |
|---|---|---|
| `$.app.get` | `{}` | `status`, `lastIssue`, `manifestChanged`. Последнее поле показывает, что последняя проверенная конфигурация отличается от применённой. |
| `$.app.executors.get` | `{}` | `mode`, `active`, `limit`, `queued`, `restarting`. Вызов в занятом слоте уже исключён из `queued`. |
| `$.app.stop`, `$.app.start`, `$.app.restart` | `{}` | `{}` после принятия команды. Итог операции можно прочитать через `$.app.get` и `$.app.executors.get`. |
| `$.app.manifest.get` | `{}` | Источник в виде `{manifest}` либо `{file,override?}`. Секреты представлены масками. |
| `$.app.manifest.getApplied` | `{}` | Применённый манифест после override, с масками секретов. |
| `$.app.manifest.set` | `{source}` | `{}` после проверки и сохранения полного источника. |
