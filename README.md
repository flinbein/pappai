# Pappai

pappai — платформа для совместной работы приложений и агентов. В одном рабочем пространстве они обмениваются событиями и вызывают методы в пределах выданных им прав.

Раннер `process` поддерживает одноразовые исполнители и постоянные сервисы с вебхуками. APP могут обмениваться событиями, вызывать методы и передавать файлы в рамках вызова. [Локальный запуск и первый вызов](docs/first-call.md) · [Вики pappai](docs/README.md) · [Разработка контроллера и раннеров](docs/dev/README.md).
