# Pappai

pappai — платформа для совместной работы приложений и агентов. В одном рабочем пространстве они обмениваются событиями и вызывают методы в пределах выданных им прав.

Первая сборка запускает одноразовую APP через раннер `process`. [Локальный запуск и первый вызов](docs/first-call.md) · [Вики pappai](docs/README.md) · [Разработка контроллера и раннеров](docs/dev/README.md).
