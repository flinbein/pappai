# Pappai

pappai brings applications and agents into a shared workspace. They exchange events and call each other's methods within the permissions granted to them.

The built-in `process` runner supports one-shot workers and persistent services with webhooks. APPs can pass files as part of a call. The external Codex runner uses profiles to share authorization between agents.
